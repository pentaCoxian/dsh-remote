Pair

  1. Open DSH Remote on the phone and tap Connect host, then scan the code above. On the phone itself, tap Open in DSH Remote instead.
  2. Allow the camera when asked. The phone is approved automatically within a second.
  3. Tap DSH Remote review host in the list. DSH Web opens; allow notifications when asked.

Try

  1. Send any message: the scripted model explains what it is.
  2. Send please use a tool: the tool call waits for your approval in DSH Web.
  3. Send notify me, then leave the app. About 45 seconds later an Approval needed notification arrives; tapping it opens the host again.
